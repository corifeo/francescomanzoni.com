Things I’ve built

vulnflow

Pipelines for public vulnerability data: NVD, KEV, EPSS, CWE, CAPEC and Patch Tuesday in one dataset. Add your own transforms, then load it to Parquet or a warehouse.

 vulntriage

An SSVC triage dashboard for vulnerability specialists. One HTML page, with no server and no dependencies, that takes each CVE through the decision points.

 vulnanalyst

A skill that answers vulnerability questions from a local NVD library, combining CVSS, EPSS and KEV, and says when its data is partial.

 vulnstate

Models each CVE as a disclosure state machine using NVD, EPSS and KEV data, so you can ask “was it a zero-day?” across a whole dataset.
